# 矩阵包版本信息设计

## 背景

矩阵包数量增加后，一个矩阵包可能对应多个前端构建版本。前端打包时会通过现有矩阵包开放写接口回传版本号和版本信息。回传方不判断版本属于运营中、送审中或其他业务状态，系统只负责按矩阵包保存并展示这些客观信息。

本功能不建立完整的生产版本实体，不改变现有矩阵包生产、各侧补充、APP 发版状态流转，也不要求系统推导版本的运营或送审属性。

## 数据模型

新增表 `matrix_package_versions`：

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `matrix_package_id` | 关联矩阵包 |
| `version_number` | 版本号 |
| `version_info` | 前端回传的版本信息，暂按文本保存，不解析内容 |
| `created_at` | 首次创建时间 |
| `updated_at` | 最近更新时间 |

增加唯一约束：`matrix_package_id + version_number`。

### 写入规则

- 同一矩阵包回传新的版本号时新增记录。
- 同一矩阵包回传已存在的 `version_number` 时更新 `version_info` 和 `updated_at`，不新增重复记录。
- 不根据矩阵包状态判断版本用途。
- 不修改现有矩阵包的 `appVersion` 字段。
- 不修改已有 APP 发版记录中的 `app_version`。

### 兼容规则

- 历史矩阵包没有版本表记录时，版本入口展示空状态。
- 历史 APP 发版记录如果找不到对应版本信息，版本信息入口展示 `-`。
- 版本信息只保留每个版本号的最新内容，不保存每次回传的修改历史。

## 对外回传接口

沿用现有 `/api/open/matrix-packages/update-fields`，继续通过矩阵包名称匹配矩阵包。

新增 `version_number` 和 `version_info` 字段。接口完成以下操作：

1. 校验矩阵包匹配结果。
2. 校验版本号非空并限制长度。
3. 根据矩阵包 ID 和版本号执行新增或更新。
4. 返回保存后的版本记录，便于外部联调确认。

版本信息内容暂不限制业务格式，只作为文本保存和展示。接口不要求外部传递 `OPERATING`、`REVIEW` 等状态字段。

## 矩阵包全景图

在“投放平台信息概览”列右侧新增“版本信息”列。

- 单元格展示该矩阵包的版本数量，例如 `3 个版本`。
- 点击后打开版本列表弹窗。
- 列表展示版本号、最近更新时间和“查看详情”按钮。
- 默认按最近更新时间倒序。
- 点击“查看详情”打开只读弹窗，展示该版本完整 `version_info`。
- 版本信息不参与筛选、生产完成、check、状态流转或投放统计。

## APP 版本发布页面

在 APP 版本发布列表新增“版本信息”列。

- 每条发版记录使用 `matrix_package_id + app_version` 匹配版本表。
- 匹配成功时展示“查看详情”按钮，不直接渲染长文本。
- 点击后打开只读弹窗，展示对应版本的完整 `version_info`。
- 未填写版本号或没有匹配记录时展示 `-`。
- 版本表后续更新后，发版列表查看到的内容使用最新版本信息。
- 不自动修改发版记录的版本号、状态、备注或其他字段。

## 接口与查询边界

- 矩阵包全景图查询需要返回版本数量或版本摘要，点击弹窗时再查询该矩阵包的版本列表。
- APP 版本发布列表需要返回是否存在对应版本信息，或返回版本记录的最小摘要；完整内容通过详情接口按版本记录查询。
- 版本详情接口只读，并沿用现有页面权限：能查看对应矩阵包或 APP 发版记录的用户可以查看版本信息。
- 写入接口继续使用现有开放接口 token 校验，不开放前端页面直接修改版本信息。

## 异常处理

- 矩阵包不存在：返回明确的匹配失败信息，不写入版本记录。
- 版本号为空：返回参数错误。
- 同一版本重复回传：按更新处理，接口保持幂等。
- 版本信息为空：允许保存，前端详情展示 `-`。
- 查询无版本数据：页面正常展示空状态，不影响矩阵包和发版列表加载。

## 不在本次范围内

- 不建立版本级生产详情、生产节点或各侧补充信息。
- 不根据版本号自动判断运营中、送审中、审核中或已上架。
- 不自动把版本信息填入 APP 发版申请表单。
- 不保存版本内容变更历史。
- 不在矩阵包状态变化时自动创建或删除版本记录。

## 验收标准

1. 同一矩阵包回传两个不同版本号后，版本列表展示两条记录。
2. 重复回传同一版本号不会产生重复数据，详情内容更新为最新值。
3. 全景图可以查看矩阵包的全部版本及版本详情。
4. APP 版本发布列表可以通过发版记录的矩阵包和版本号查看对应版本详情。
5. 无匹配版本信息时展示 `-`，不影响列表其他字段和现有流程。
6. 版本信息较长时仍能在弹窗中完整查看，不撑宽列表。
